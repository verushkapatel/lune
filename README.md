# Lune's open library

Public-domain piano scores for [Lune](https://lune.page), served to the app from
this branch through raw.githubusercontent.com.

Source: [PDMX](https://github.com/pnlong/PDMX) (Long et al., 2024), MuseScore scores
their uploaders released as Public Domain Mark or CC0. Lune keeps only solo piano
music by composers who died in 1954 or earlier, traditional melodies and
public-domain hymns, so an uploader's licence never stands in for a copyrighted
song. Each score was written as MusicXML by `scripts/pdmx_convert.py` on the main
branch from the dataset's own note data; Lune divides each piano part between the
two staves itself. Every file here was checked to render in Lune before it was listed.
